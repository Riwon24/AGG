# JEVision 이진 평가 (AGG0+AGG1 vs AGG2): 타일 집합 비교

`../jev` 의 JEVision(0.8B) zero-shot 타일 점수를 **AGG0+AGG1 (음성) vs AGG2 (양성)** 이진 분류로 평가하고, 같은 평가를 두 가지 타일 집합에서 비교한 실험이다. 학습(재학습)은 하지 않았고 분류 기준(임계값 하나)만 학습 fold 이미지에서 골랐다.

- **A. 기존 타일 1,514개**: `../jev/scripts/run_tiles.py` 를 수정 없이 다시 실행한 결과 (preproc 의 선택 타일, 시편 마스크 안쪽 타일만).
- **B. DINOv2_grid_augmentation 의 분석 타일 2,591개**: `jv02_run_grid_tiles.py` (타일 목록 경로만 바꾼 같은 코드), 가장자리·배경이 섞인 타일 포함.

## 설정

- 이미지: 10x 60장. AGG0 28 / AGG1 14 / AGG2 18 → 음성 42 / 양성 18 (다수 클래스 0.700).
- 이미지 점수: 타일 `p_flat` 의 평균 (`mean_flat`, primary) 또는 `p_flat > 0.5` 인 타일의 비율 (`frac_flat`, 보조). 두 정의는 `../jev/scripts/agg_tiles.py` 와 같다.
- 분류: 점수 ≥ 임계값 이면 AGG2. 임계값은 학습 이미지의 점수값 중 학습 accuracy 가 처음으로 최대가 되는 값으로, **학습 fold 이미지에서만** 고른다. test 점수는 예측에만 쓴다 (분할 서로소, 모든 이미지가 한 번 test, 학습에 두 클래스 존재를 assert 로 확인).
- 평가: 이미지 단위 층화 5-fold × 10 반복 (IMG), LOCO (처리 조건 1개 제외, 10 fold), LOMO (처리 방법 1개 제외, 5 fold). 이미지 단위/처리 조건 단위 부트스트랩 95% CI (2000회), 라벨 순열 검사 20회.
- 재실행 확인 (A): 재실행한 `p_flat` 이 기존 `tiles_v1.jsonl` 과 1,514개 모두 같다 (차이 0). AUROC (AGG2>AGG0 0.944, AGG2>AGG1 0.913) 도 `../jev` README 값과 같다.

## 해석 (가능한 설명이며 확정이 아님)

- **A 에서는** 점수가 기준선 (항상 AGG0/1, 같은 온도 규칙) 보다 높지만, 처리 방법 규칙 (NPH 이면 AGG2, 0.895) 과 구분되지 않는다. 양성 18장 중 NPH 가 12장, PH1180-1050 이 5장, PH1205-1050 이 1장이라 양성 라벨이 처리 방법과 거의 겹친다. AGG2 를 본 것인지 NPH 이미지의 외형을 본 것인지는 이 점수로 구분할 수 없다.
- **B 에서는** 신호가 사라졌다 (AUROC 0.934 → 0.572, 양성 recall 0.11~0.22, 항상 AGG0/1 예측과 구분되지 않음). 이미지 점수가 타일 점수의 평균이라 가장자리·배경이 섞인 타일 (B 에는 1,282개, 절반가량) 이 평균에 섞였을 가능성이 있다. 다만 타일 집합과 함께 격자 위치와 타일 수도 달라져 원인을 가르지 못했다. 마스크 100% 타일만 쓴 집계는 하지 않았다.
- 이전 점검 (`../jev` README 5절) 에서 이 모델의 타일 점수는 조명 줄무늬, 스크래치, 이물질에도 반응했다.

## 한계

1. 이미지 60장 (양성 18장) 이고 양성이 소수 조건에 몰려 있어 CI 가 넓다. 이미지 단위 CI 는 이미지를 독립으로 보아 처리 조건 단위 CI 보다 좁다.
2. 점수 정의와 프롬프트는 `../jev` 의 것을 그대로 썼고, 60장 전체를 본 뒤 정해졌다. 같은 온도, 처리 방법, 처리 조건 기준선은 결과를 본 뒤 추가했다.
3. 이 이진 라벨로는 DINOv2 를 돌린 적이 없어 비교하지 않았다. 재학습, 다른 프롬프트 등 확장은 하지 않았다.

|---|---|
