# AGG 이미지 전처리 (10x, 시편 마스크 + 유효 타일 좌표)

광학 현미경 이미지(파란 시편, 어두운 배경)에서 **시편 안에 100% 들어오는 224px 타일의 좌표**를 정하는 전처리 파이프라인.
AGG0 / AGG1 / AGG2 분류 과제의 1차 실험용(10x 이미지만 사용).

- 범위: 시편 마스크 → 안쪽 마진 → 스케일바 제외 → 유효 타일 좌표. **특징 추출(DINOv2), 데이터 분할, 학습은 이 단계에서 하지 않았다** (이후 단계는 `../exp/README.md`, 전체 흐름은 `../README.md`).
- 원본 이미지는 읽기 전용. 배경을 지우거나 칠하지 않는다. 불량 타일은 좌표 목록에서 제외만 한다.
- 모든 실행은 단계 이름이 붙은 파이썬 스크립트이고, 파라미터는 `config.yaml` 한 곳에 있다.

## 용어

사용자 확인(2026-10-12)에 따른 폴더 이름의 의미. **코드/CSV의 열 이름(`treatment`, `sample`)과 뜻이 다르니 주의.**

| 폴더 | 의미 | 값 | 코드/CSV 열 |
|---|---|---|---|
| 1단계 (`BASE`, `BASE-LC` ...) | **금속 종류** | BASE, BASE-LC, BASE-LCSI, BASE-LSi, REF, REF-LN (6종) | `treatment` |
| 2단계 (`NPH1035`, `PH1180-1050` ...) | **처리 조건** = 처리 방법 x 온도 | 처리 방법 NPH, PH1180, PH1205, PH1230, PH1255 (5종) x 온도 1035, 1050 (2종) = 10종 | `sample` |
| `금속/처리 조건` 폴더 | 묶음 (같은 시편의 여러 배율) | 6 x 10 = 60개, 10x는 묶음당 1장 | `group` |

"시편"은 현미경으로 찍은 파란 물체 자체를 가리킨다(예: 시편 영역 마스크).

```

    ├── s03_mask_qc.py  s04_tile_grid.py  s05_tile_stats.py  s06_make_figures.py  s07_label_crosstab.py   # 파이프라인 (s00 ~ s07 9개가 전부)
    ├── overrides/                # mag_overrides.csv(배율 예외, s00b가 읽음), README.txt(마스크 override 형식; 현재 미사용)
```

## 4. 실행 방법

```powershell
cd AGG_labeled_only\preproc
.\.venv\Scripts\python.exe run_all.py            # 전체 (약 1~2분)
.\.venv\Scripts\python.exe s04_tile_grid.py      # 단계 하나만 (모두 --config/--input/--output 인자 지원)
```

- 환경: Python 3.11, numpy / opencv-python-headless / scipy / pillow / pyyaml / matplotlib (`requirements_freeze.txt`).
- 이 PC에서는 Windows 애플리케이션 제어 정책이 `pandas`와 `skimage`의 DLL 로딩을 차단한다. 우회하지 않고 해당 패키지를 쓰지 않는다(표준 `csv`, `cv2`, `scipy.ndimage`로 구현).
- 같은 입력이면 같은 출력이 나오도록 seed를 고정했다 (`config.yaml: seed`, 이미지/조합별 seed는 `image_id`에서 파생).
- 모든 스크립트가 `outputs/<스크립트명>/log.txt`에 사용한 파라미터, 처리 개수, 건너뛴 파일과 사유를 남긴다.

## 6. 단계별 결과 (확인된 사실)

### 6.1 데이터 (s00, s00b)
- 이미지 179장 모두 1824x1368, RGB JPEG. 원본 마스터 폴더에서 복사한 파일이 경로까지 모두 일치(179/179, 해시 동일).
- 라벨: AGG0 83 / AGG1 43 / AGG2 53 (파일명 끝의 `AGG<n>`에서만 파싱). 같은 `금속/처리 조건` 묶음 안에서 라벨이 섞인 경우는 없음(배율이 달라도 라벨 같음).
- **라벨과 처리 조건(2단계 폴더명)이 강하게 얽혀 있다.** 예: NPH1035, NPH1050은 전부 AGG2, PH1205-1035, PH1230-1035, PH1255-1035, PH1255-1050은 전부 AGG0. 교차표와 수치는 7절과 `outputs/s07_label_crosstab/` 참조.
- 배율별 장수(이름 + 메타 + 사용자 확인 반영): 7.5x 59 / 10x 60 / 12.5x 60. 묶음(금속/처리 조건)은 60개이며, 묶음당 3장(배율 각 1장)이 아닌 묶음이 5개: 2장짜리 3개(`BASE-LCSI/PH1205-1050`, `BASE-LSi/PH1205-1050`, `REF-LN/PH1180-1050`), 4장짜리 2개(`BASE-LSi/PH1180-1050`은 12.5x가 2장, `REF-LN/PH1180-1035`는 7.5x가 2장). 10x는 60개 그룹 모두 정확히 1장.
- 파일명 규칙에 안 맞는 이름 16장(`x101`, `x10#!`, `x7.51`, `x12.54` 등)은 모두 xlif 시야 폭이 해당 배율 기준값과 0.74% 이내로 일치해 배율을 확정.
- xlif가 없는 파일 4장, 정상 이름인데 xlif와 배율이 다른 파일 2장(위의 배율 예외 중 2건).
- 10x 60장의 라벨은 AGG0 28 / AGG1 14 / AGG2 18.

### 6.2 스케일바 (s01)
- 스케일바 박스는 오른쪽 아래에 고정되어 있다: 오른쪽 끝 x=1813, 위 y=1293, 아래 y=1358~1359. 왼쪽 끝은 눈금 길이에 따라 달라 10x는 1686~1687.
- **눈금 값이 이미지마다 다르다** (대부분 "1 mm", 일부 7.5x는 "2.5 mm", 일부 12.5x는 "750 µm"). 군집별 대표를 눈으로 확인.
- 10x 제외 구역 = 박스 모델 [1686, 1293, 1813, 1359] + 여유 16px, 이미지 경계로 자름 → **[1670, 1277, 1824, 1368]**.
- 막대 기준 px/mm는 xlif 기준보다 중앙값 5.5% 작다(10x: 막대 약 92 vs 메타 약 97). 어느 쪽이 맞는지는 이 데이터로 판단할 수 없다. 타일은 픽셀 단위라 영향 없음.

### 6.3 시편 마스크 (s02, s03)
- 시편은 프레임 대부분을 덮는 파란 정사각형. 마스크 면적 비율은 중앙값 0.705 (0.589~0.814), 클래스별 중앙값 AGG0 0.697 / AGG1 0.708 / AGG2 0.732.
- 방법 비교 (`otsu_v` 대비 IoU 중앙값): 채도 Otsu `otsu_s` 0.913 (배경으로 누출, 27장이 IoU<0.9), 채도+명도 `otsu_sv` 0.985, 색상 기반 `hue_sv` 0.991, 고정 임계값은 방법에 따라 0.83~0.97.
- **`otsu_v` 선택 이유**: 배경(V≈40)과 시편(V≈150)의 명도 차이가 크고, `hue_sv`는 시편 가장자리의 밝은 흰 띠(채도가 낮음)를 잘라내는 이미지가 6장, 시편 밖 어두운 띠를 포함하는 이미지가 1장 있었다 (비교 스크립트와 출력은 삭제했고 수치만 남음).
- 프레임 잘림(마스크가 이미지 경계에 닿음) 36장: 위 26, 아래 17, 오른쪽 1, 왼쪽 0. 18장은 위/아래 경계의 50% 넘게를 시편이 덮는다.
- QC 우선순위: A(먼저 확인) 5장, B(프레임 잘림만) 32장, 문제 없음 23장. A 5장은 윤곽선 overlay로 확인했고 마스크는 대체로 정상.

### 6.4 타일 (s04)

| 단계 | 개수 |
|---|---|
| 격자 (15x11) | 165개/장, 합계 9,900 |
| valid (마스크 안 + 스케일바와 안 겹침) | 5,190 (52.4%), 이미지당 72~110 (평균 86.5) |
| 제외 | `outside_mask` 4,590 (46.4%), `outside_mask + scalebar_overlap` 120 (1.2%) |
| **선택 (겹치지 않는 부분 격자, 상한 없음)** | **1,514**: AGG0 690 / AGG1 360 / AGG2 464, 이미지당 20~30개 (평균 25.2; 25개 40장, 30개 5장, 29개 3장, 나머지 12장) |

- valid 타일이 0개인 이미지는 없다. 스케일바와 겹치는 타일은 전부 마스크 밖이기도 해서 스케일바 규칙은 마스크 규칙과 겹쳐서 작동한다.
- 격자는 (0,0)에서 시작하며 오른쪽 32px, 아래 24px는 쓰지 않는다.
- **선택 규칙(`nonoverlap_best_phase`)**: stride 112 격자에서 가로세로 한 칸씩 건너뛰면 타일이 서로 겹치지 않는다(타일 224 = 2 x stride). 건너뛰는 시작 위치(오프셋) 4가지 중 valid 타일이 가장 많은 것을 이미지마다 고른다(동점이면 (0,0), (0,1), (1,0), (1,1) 순). 무작위가 없는 결정적 규칙이다.
- 선택 타일의 분포: valid 영역 대비 커버리지 94.9% (빈 공간 5.1%), 한 픽셀이 덮이는 타일 수 1 (겹침 0). 비교로 이전의 겹치는 선택(무작위 상한 40)은 커버리지 83.8%, 빈 공간 16.2%, 최대 4개 겹침이었다 (비교 스크립트와 출력은 삭제했고 수치만 남음).
- assert로 확인: 모든 타일이 이미지 범위 안, 선택 수 = 부분 격자 크기, **같은 이미지의 선택 타일끼리 겹치는 쌍 0개**.

### 6.5 밝기/색 통계 (s05)
- 시편 영역 평균은 클래스 간에 거의 같다 (V: AGG0 146.1 / AGG1 145.5 / AGG2 144.0, S: 75.2 / 75.5 / 73.2). 분산설명비율(η²) 클래스 0.000~0.009.
- 색 분산을 더 설명하는 것은 금속 종류(η² 0.18~0.24)와 처리 조건(0.04~0.17)이다 (금속마다 색이 다르다). 선택 타일 기준에서도 클래스 간 차이는 거의 없다.
- 이 결과는 **이미지 단위 평균 색**에 대한 것이고, 타일 안의 질감 정보는 반영하지 않는다.

### 알려진 한계와 주의
- **마스크 오류 2장** (override를 쓰지 않기로 해서 그대로 남음): `BASE-LC/PH1230-1035`은 오른쪽 위 밝은 배경이 시편으로 잡혀 valid 96개 중 약 9개가 배경이 섞였을 수 있고, `BASE-LCSI/NPH1035`는 오른쪽 위 그림자 부분이 빠져 valid에서 약 3개를 놓쳤을 수 있다(`hue_sv` 비교 기준의 추정). 나머지 마스크는 contact sheet로 전수 확인하지는 못했다.
- **`REF-LN/NPH1050/x10#1`**: 이미지 안의 스케일바(1mm = 66px)와 xlif가 모두 7.5x 값인데, 사용자 확인에 따라 10x로 쓴다. 타일 크기는 픽셀 단위라 영향은 없지만 물리 크기를 해석할 때 주의.
- **라벨은 처리 조건(처리 방법 x 온도)의 함수에 가깝다 (가장 중요, `s07_label_crosstab`)**: 처리 조건(10종)의 다수 라벨로 라벨을 맞히면 **54/60 = 90%** 일치(전체 다수 클래스 기준선 46.7%), Cramér's V 0.863. 처리 방법만으로는 75% (V 0.693), 온도만으로는 51.7% (V 0.335), **금속 종류로는 46.7%로 기준선과 같다(V 0.175)**. 표본이 작아 p 값은 참고용이다.
  - 처리 방법 x 온도 → 라벨 (이미지 수 AGG0/AGG1/AGG2, 칸당 금속 6종 x 1장 = 6장):

    | 처리 방법 | 1035 | 1050 |
    |---|---|---|
    | NPH | 0/0/6 | 0/0/6 |
    | PH1180 | 1/5/0 | 0/1/5 |
    | PH1205 | 6/0/0 | 1/4/1 |
    | PH1230 | 6/0/0 | 2/4/0 |
    | PH1255 | 6/0/0 | 6/0/0 |

  - **온도 효과**: 1035 → 1050에서 다수 라벨이 PH1180은 AGG1 → AGG2, PH1205는 AGG0 → AGG1, PH1230은 AGG0 → AGG1로 한 단계 올라간다. NPH(전부 AGG2)와 PH1255(전부 AGG0)는 두 온도에서 같다.
  - **금속 효과**: 같은 처리 조건 안에서 다수 라벨과 다른 이미지는 6장뿐이다. BASE-LCSI가 라벨이 한 단계 낮은 경우가 4번(PH1180-1035, PH1180-1050, PH1205-1050, PH1230-1050), BASE-LSi가 높은 경우 1번(PH1205-1050), REF-LN이 낮은 경우 1번(PH1230-1050). 금속별 라벨 비율은 대체로 40/30/30%인데 BASE-LCSI만 AGG0가 70%다. **처리 조건과 독립된 신호는 이 소수의 금속에 따른 라벨 변화뿐이다.**
  - 다수 라벨 기준 처리 조건 수는 AGG0 4종, AGG1 3종, AGG2 3종뿐이다.
  - **분할 단위에 따라 무엇이 train과 test에 함께 들어가는가** (그룹 하나를 통째로 test로 뺄 때, `split_options.csv`):

    | 분할 단위 | 그룹 수 | test가 한 클래스뿐인 그룹 | train에서 클래스가 빠지는 그룹 | 같은 처리 조건/방법이 train에 남는가 |
    |---|---|---|---|---|
    | 금속 종류 | 6 | 0 | 0 | 처리 조건 10종이 모두 남음 |
    | 처리 조건(방법 x 온도) | 10 | 6 | 0 | 같은 방법의 다른 온도는 남음 |
    | 처리 방법(온도 둘 다 묶음) | 5 | 2 (NPH, PH1255) | 0 | 같은 방법은 모두 test로 빠짐 (NPH를 빼면 train의 AGG2는 6장뿐) |

  - **[해석] 분할 단위에 따라 평가가 의미하는 것이 달라진다.** 라벨이 처리 조건에 90% 좌우되므로, 금속 종류로만 나누면 같은 처리 조건이 train/test에 모두 있어서 모델이 처리 조건의 외형만 알아봐도 높은 점수를 얻을 수 있다(AGG 자체를 보는지 구분할 수 없음). 새 처리 조건에 대한 일반화를 보려면 처리 조건 단위로, 같은 처리 방법의 다른 온도도 비슷해 보인다면 처리 방법 단위(5개)로 나눠야 한다. 이전 README의 "시편 단위 분할"은 이 구분이 모호했다. **분할 단위는 연구 목적에 따라 정해야 하는데, 이후 모델·실험 단계에서 사용자가 이미지 단위로 결정했다 (이 선택의 한계는 `../exp/README.md` 12절).**
  - 처리 조건 또는 처리 방법 단위로 나누면 fold의 test가 한 클래스뿐인 경우가 많아(10개 중 6개, 5개 중 2개) fold별 지표는 의미가 없고, fold를 합친 예측으로 평가해야 한다. 같은 클래스의 처리 조건이 3~4종뿐이라 결과의 분산이 클 수 있다.
  - 색 통계(`s05`)에서 클래스 간 색 차이는 거의 없고(η² 0.000~0.009) 금속 종류(0.18~0.24)와 처리 조건(0.04~0.17)이 색 변동을 더 설명한다. 이것은 모델이 금속/처리 조건을 구별할 단서(색)가 있다는 정도만 말해준다. 모델이 실제로 그것을 구별해 쓰는지는 이 단계에서 확인하지 않았다.
- 같은 이미지의 타일은 반드시 같은 쪽에 둬야 한다. 선택 타일은 서로 겹치지 않지만 같은 이미지(그리고 같은 처리 조건)에서 나온 타일은 비슷하다.
- 클래스별 선택 타일 비율은 이미지 비율과 거의 같다(타일 45.6% / 23.8% / 30.6% vs 이미지 46.7% / 23.3% / 30.0%). 이미지 수 자체의 불균형(28/14/18)은 해결되지 않으므로 학습 시 클래스 가중치가 필요할 수 있다. (겹치는 격자에서 valid 타일 수는 클래스마다 달랐다: AGG2 평균 90.0, AGG0 83.8, AGG1 87.5, Kruskal p=0.0485.)
- 선택 타일 수는 이미지마다 20~30개로 다르다 (상한 없음). 이미지당 기여를 완전히 같게 하려면 상한을 두면 되지만, 상한 20을 씌우면 이미지당 약 5개가 빠져 빈 공간이 24%로 늘어서 쓰지 않았다.
- 안쪽 마진 32px은 시편 가장자리의 밝은 반사 띠(폭 약 40~50px)를 대부분 피하지만, 가장자리에 AGG 결함이 많다면 그 정보를 놓칠 수 있다(이 데이터로는 판단 불가).
- 5개 묶음의 배율 불일치(위 6.1)와 xlif 4장 누락 중 10x에 걸리는 것은 `BASE-LSi/PH1205-1050/x10#4`(xlif 없음, 스케일바로 10x 확인) 1장뿐이다. 나머지는 10x 1차 실험에 영향이 없다.
